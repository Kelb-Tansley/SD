The test correctly expects ArgumentNullException when passing null to GenerateBeamChains, but the production code throws NullReferenceException instead. The GenerateBeamChains method (line 9-13) lacks null parameter validation. When beams is null, the foreach statement at line 11 attempts to enumerate a null collection, causing a NullReferenceException. The method should validate the beams parameter and explicitly throw ArgumentNullException if it's null, following .NET best practices for parameter validation.

### Suggested Fix
Add null parameter validation at the beginning of the GenerateBeamChains method in BeamChainService.cs. The fix should be added at line 10-11:

```csharp
public void GenerateBeamChains(List<Beam> beams)
{
    if (beams == null)
        throw new ArgumentNullException(nameof(beams));
        
    foreach (var beam in beams)
        GenerateBeamChain(beams, beam);
}
```

This ensures that when a null list is passed, the method throws ArgumentNullException with a clear indication of which parameter is null, rather than allowing a NullReferenceException to occur during enumeration.
